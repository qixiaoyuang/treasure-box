# 跳一跳 TiaoYiTiao

Android 开屏广告自动跳过工具。基于无障碍服务，自动识别并点击广告上的「跳过」按钮。

## 功能

- **自动跳广告**：识别「跳过」按钮、倒计时按钮；点按无效时自动改用手势点击或返回键
- **摇一摇广告识别**：顶部出现"摇一摇"字样即按广告处理，抢在误触前关闭
- **应用加强名单**：对指定 App 使用更激进的跳过策略（启动初期无障碍树无按钮时尝试右上角盲点）
- **跳过计数**：今日 / 累计
- **诊断日志**：可开关、可落盘，方便排查
- **快捷设置磁贴**：一键查看状态 / 跳转无障碍设置
- 中英双语（跟随系统语言）
- 无联网权限，离线可用

## 使用

1. 安装后打开 App，点「无障碍管理」开启跳一跳的无障碍服务
2. 建议同时点「防止被系统清理掉」，按指引加电池优化白名单和自启动
3. 需要激进策略的 App，在「应用加强」里打开开关

## 构建

本项目使用手工构建脚本（aapt2 → javac → d8 → zipalign → apksigner），不依赖 Gradle：

```bash
./build_manual.sh
```

需要：JDK 17、Android SDK（build-tools 34.0.0、platform android-34）。

> 图片资源：`app/src/main/res/drawable-nodpi/` 下的 `ic_rabbit_fg.png`（应用图标前景）
> 与 `app_bg_rabbit.png`（界面水印）为二进制文件，需自行放入该目录后再构建。

> 签名：本仓库不含 `debug.keystore`。首次构建时脚本会自动生成；如需与已发布版本
> 保持同签名覆盖安装，请把原 `debug.keystore` 放到仓库根目录再构建。

## 权限用途

| 权限 | 用途 |
|---|---|
| 无障碍服务 | 跳广告：识别并点击开屏广告的跳过按钮 |
| 前台服务 | 保活无障碍服务 |
| 忽略电池优化 | 防止后台被系统清理 |
